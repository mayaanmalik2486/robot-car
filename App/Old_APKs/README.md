# Old app versions

Every version of the Robot Car app, oldest first. The newest one is always `../RobotCar.apk` (now 4.0, November 10 2026: smooth steering, the GameSir Cyclone 2 map, settings, the controller screen).

| File | Version | What it was |
|---|---|---|
| RobotCar_v1.0.apk | 1.0 (Oct 19, 2026) | First app: portrait, a button for every mode, live status |
| RobotCar_v2.0.apk | 2.0 (Oct 19, 2026) | Game-pad layout, landscape, emoji buttons, game controller support |
| RobotCar_v3.0.apk | 3.0 (Oct 20, 2026) | Tilt driving, Moves / Play / Radar pages, radar map, song name, pressable buttons, racing controller map |
| RobotCar_v3.1.apk | 3.1 (Oct 20, 2026) | Spots an old car program, speed button fix, link log, safer screen tap |

To install an older one, download it on the phone and install it. Android only lets you install an
OLDER version after uninstalling the newer one first.
